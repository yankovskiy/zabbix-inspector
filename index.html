📋 Требования к архиву

ZIP архив должен содержать следующие файлы:

  • vmstat.txt - вывод команды vmstat

  • zabbix_config.txt - конфигурация Zabbix
  • os_release.txt - Информация о сервере
  • uptime.txt - время работы системы и загрузка
  • nproc.txt - количество процессорных ядер
  • cpuinfo.txt - информация о процессоре
  • final.txt - дата и время завершения сбора диагностической информации
  • database/*.csv - результаты выполнения диагностических запросов к БД

О сервисе

Zabbix Inspector — это веб-приложение для анализа диагностических данных Zabbix серверов. Инструмент предоставляет интерактивные графики и таблицы для исследования производительности системы, состояния процессов, использования кэшей и других критических метрик.

Приложение работает полностью в браузере пользователя без передачи данных на внешние серверы, что обеспечивает максимальную безопасность конфиденциальной информации.

⚠️
Безопасность данных

Все данные обрабатываются локально:

  • ZIP-архивы анализируются исключительно в браузере пользователя
  • Никакие данные не передаются на внешние серверы
  • Приложение может работать без подключения к интернету
  • Вся обработка выполняется с помощью JavaScript в песочнице браузера

Дополнительная защита:

  • Python-сборщик автоматически фильтрует чувствительные параметры конфигурации
  • Исключаются пароли баз данных, ключи шифрования и другие секреты
  • Сохраняются только технические параметры, необходимые для диагностики
Сбор диагностических данных

Использование Python сборщика:

Базовое использование:
python3 python/zdiag.py
С указанием директории:
python3 python/zdiag.py --output-dir /tmp/my-zabbix-diag
С диагностикой базы данных:
python3 python/zdiag.py --db --sql-dir python/sql
Все параметры:
python3 python/zdiag.py --output-dir /tmp/diag --stats-timeout 120 --db

Параметры командной строки:

  • --output-dir — директория для сохранения результатов (по умолчанию: /tmp/zabbix-diag)
  • --stats-timeout — таймаут для сбора статистики в секундах (по умолчанию: 60)
  • --keep-temp-config — сохранить временный конфигурационный файл
  • --db — включить сбор диагностических данных из базы данных
  • --db-init — настроить подключение к базе данных (интерактивно)
  • --sql-dir — директория с SQL-запросами для диагностики БД
  • --version — получить версию сборщика
Системные требования

Для сбора данных:

  • Python 3.7 или выше
  • Операционная система Linux
  • Доступ к процессам Zabbix server
  • Права на чтение конфигурационных файлов Zabbix

Для анализа данных:

  • Современный веб-браузер с поддержкой ES6 модулей
  • JavaScript должен быть включен
  • Минимум 1 ГБ оперативной памяти для обработки больших архивов

Процесс анализа

Пошаговая инструкция:

  1. Запустите Python сборщик на Zabbix сервере
  2. Дождитесь создания ZIP архива
  3. Скопируйте архив на рабочую станцию
  4. Откройте Zabbix Inspector в браузере
  5. Загрузите ZIP архив через интерфейс
  6. Изучите данные в соответствующих разделах приложения

Разделы анализа:

  • Обзор системы — общее состояние сервера и ключевые метрики
  • Производительность — графики CPU, памяти и утилизации процессов
  • Vmstat — детальный анализ системных метрик
  • Процессы Zabbix — таблица процессов с фильтрацией
  • Diaginfo — подробная диагностика кэшей и очередей
  • Конфигурация — параметры zabbix_server.conf
